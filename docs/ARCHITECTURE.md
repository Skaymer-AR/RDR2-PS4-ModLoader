# Architecture

## Track A: resources
Evaluate GoldHEN AFR redirection with a non-destructive, known-safe test. Redirection does not imply RPF or PC mod compatibility.

## Track B: runtime
Investigate a version-specific PRX plugin using GoldHEN SDK and approved local debugging. Do not reuse offsets from another CUSA/update without verification.

## Catalog
Manifests declare mod ID, type, supported CUSA, update and resource paths. Conflicting overrides must be rejected.

## Safety
No game binaries in Git; backups before tests; default disabled; log failures; no network or online-mode testing.
